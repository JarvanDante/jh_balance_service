# DAO 自定义方法使用指南

## 📋 概述

本项目的 DAO 文件支持自动生成和自定义方法共存。`gen_pb_clean.sh` 脚本会：

- ✅ 保留 `// Add your custom methods and functionality below.` 之后的所有自定义方法
- ✅ 保留 import 中的所有自定义包
- ✅ 重新生成标准的 DAO 结构

## 🔧 如何添加自定义方法

### 1. 在正确的位置添加方法

**✅ 正确示例**：

```go
// Add your custom methods and functionality below.

// GetByUserIdWithLock 根据用户ID查询余额（加锁）
func (d balanceUserDao) GetByUserIdWithLock(ctx context.Context, siteId, userId int64) (*entity.BalanceUser, error) {
    var balanceUser *entity.BalanceUser
    err := d.Ctx(ctx).
        Where("site_id", siteId).
        Where("user_id", userId).
        LockUpdate().
        Scan(&balanceUser)
    return balanceUser, err
}
```

**❌ 错误示例**：

```go
// 不要在这个注释之前添加方法
func (d balanceUserDao) MyMethod() {} // ❌ 会被覆盖

// Add your custom methods and functionality below.
```

### 2. 添加必要的 import

如果你的自定义方法使用了额外的包，需要在 import 中添加：

```go
import (
    "context"
    "fmt"  // 如果使用 fmt.Sprintf
    "jh_balance_service/internal/dao/internal"
    "jh_balance_service/internal/model/entity"  // 如果使用 entity

    balanceConsts "jh_balance_service/internal/consts/backend/balance"  // 如果使用常量
    "github.com/gogf/gf/v2/database/gdb"
    "github.com/gogf/gf/v2/frame/g"  // 如果使用 g.Map
    "github.com/gogf/gf/v2/os/gtime"  // 如果使用 gtime.Now()
)
```

**脚本会保留你添加的所有 import！**

## 📝 常用的自定义方法模式

### 1. 查询方法

```go
// GetByXXX 根据条件查询
func (d xxxDao) GetByUserId(ctx context.Context, userId int64) (*entity.XXX, error) {
    var result *entity.XXX
    err := d.Ctx(ctx).
        Where("user_id", userId).
        Scan(&result)
    return result, err
}

// GetByXXXWithLock 查询并加锁
func (d xxxDao) GetByUserIdWithLock(ctx context.Context, userId int64) (*entity.XXX, error) {
    var result *entity.XXX
    err := d.Ctx(ctx).
        Where("user_id", userId).
        LockUpdate().
        Scan(&result)
    return result, err
}
```

### 2. 更新方法

```go
// UpdateXXX 更新特定字段
func (d xxxDao) UpdateStatus(ctx context.Context, id int64, status int) error {
    _, err := d.Ctx(ctx).
        Where("id", id).
        Update(g.Map{
            "status":     status,
            "updated_at": gtime.Now(),
        })
    return err
}
```

### 3. 复杂 SQL 操作

```go
// FreezeBalance 冻结余额（使用 SQL 表达式）
func (d balanceUserDao) FreezeBalance(ctx context.Context, siteId, userId int64, amount float64) error {
    _, err := d.Ctx(ctx).
        Where("site_id", siteId).
        Where("user_id", userId).
        Update(g.Map{
            "balance":        gdb.Raw(fmt.Sprintf("balance - %.4f", amount)),
            "balance_frozen": gdb.Raw(fmt.Sprintf("balance_frozen + %.4f", amount)),
            "updated_at":     gtime.Now(),
        })
    return err
}
```

### 4. 创建方法（带参数结构体）

```go
// CreateXXXParams 创建参数
type CreateXXXParams struct {
    SiteId   int64
    UserId   int64
    Amount   float64
    // ...
}

// CreateXXX 创建记录
func (d xxxDao) CreateXXX(ctx context.Context, params *CreateXXXParams) error {
    _, err := d.Ctx(ctx).Insert(g.Map{
        "site_id":    params.SiteId,
        "user_id":    params.UserId,
        "amount":     params.Amount,
        "created_at": gtime.Now(),
        "updated_at": gtime.Now(),
    })
    return err
}
```

### 5. 检查方法

```go
// HasPendingOrder 检查是否有待处理订单
func (d xxxDao) HasPendingOrder(ctx context.Context, userId int64) (bool, error) {
    count, err := d.Ctx(ctx).
        Where("user_id", userId).
        Where("status", balanceConsts.StatusPending).
        Count()
    if err != nil {
        return false, err
    }
    return count > 0, nil
}
```

### 6. 事务包装器

```go
// Transaction 事务包装器
func (d xxxDao) Transaction(ctx context.Context, fn func(ctx context.Context) error) error {
    return d.Ctx(ctx).Transaction(ctx, func(ctx context.Context, tx gdb.TX) error {
        return fn(ctx)
    })
}
```

## 🚀 运行脚本

### 生成 protobuf 并更新 DAO

```bash
cd jh_balance_service
bash scripts/gen_pb_clean.sh
```

脚本会：

1. 生成 protobuf 文件
2. 清理 omitempty 标签
3. 更新所有 DAO 文件（保留自定义方法和 import）
4. 格式化代码


## ⚠️ 注意事项

### 1. 自定义方法位置

- ✅ 必须在 `// Add your custom methods and functionality below.` 之后
- ❌ 不要在这行注释之前添加方法

### 2. Import 管理

- ✅ 脚本会保留你添加的所有 import
- ✅ 不需要的 import 可以手动删除，脚本不会自动清理

### 3. 方法命名规范

- 使用清晰的方法名，如 `GetByUserId`、`UpdateStatus`
- 复杂操作使用参数结构体，如 `CreateXXXParams`
- 返回值统一使用 `(result, error)` 模式

### 4. 错误处理

- 所有方法都应该返回 error
- 使用 `gerror.Wrap()` 包装错误，保留错误链

### 5. 事务管理

- 事务应该在 Domain 层或 Logic 层管理
- DAO 层只提供事务包装器

## 🎯 总结

1. **自定义方法**：放在 `// Add your custom methods and functionality below.` 之后
2. **Import**：脚本会自动保留你添加的所有 import
3. **运行脚本**：`bash scripts/gen_pb_clean.sh`
4. **验证**：`go build .`

这样就可以安全地添加自定义方法，不用担心被脚本覆盖！🎉
